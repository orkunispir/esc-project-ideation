# ESC method routing

Use one method per response, then apply the ESC grounding pass. The method generates or transforms possibilities; the grounding pass tests whether a direction could become real solidarity work.

## Phase-first routes

| Phase | Route | ESC use |
|---|---|---|
| Generating from a named need or domain | `full-prompt-library.md` or `leverage-points.md` | Turn a broad need into constrained project shapes and intervention points. |
| Expanding an existing concept | `methods/scamper.md` | Produce variations without losing the core community mechanism. |
| Selecting between directions | `methods/premortem-and-inversion.md` | Expose delivery, partnership, safeguarding, and evidence failures before choosing. |
| Unblocking a stale plan | `methods/oblique-strategies.md` | Introduce a controlled displacement, then translate it back into a testable activity. |
| Making a safe idea less obvious | `methods/lateral-provocations.md` | Break generic “youth empowerment/platform” shapes; keep the need and community visible. |
| Refining a project that feels abstract | `methods/defamiliarization.md` | Describe the work from the resident, volunteer, or partner’s concrete point of view. |
| Synthesizing records, interviews, or notes | `methods/affinity-diagrams.md` | Cluster needs, mechanisms, actors, and gaps; do not equate frequency with importance. |
| Needing a research question | `methods/compression-progress.md` | Prefer a question whose answer changes what the organisation can do. |
| Attacking a known implementation problem | `methods/polya.md` or `methods/first-principles.md` | Separate the actual constraint from inherited application language. |
| Engineering a tool or data workflow | `methods/triz-principles.md` or `methods/pattern-languages.md` | Resolve a real contradiction or reuse a proven structure; avoid tool-first ideation. |

## Domain routes

- **Community or institutional change:** `leverage-points.md`.
- **Participatory activity or social design:** `analogy-and-blending.md` when a remote structure can unlock a fresh format; otherwise use `full-prompt-library.md` Social / collective.
- **Digital or physical artefact:** `first-principles.md` for assumptions, `triz-principles.md` for parameter conflicts, `biomimicry.md` for a genuine natural-system analogue.
- **Service or partner offer:** `jobs-to-be-done.md`, but define the community relationship before the service wrapper.
- **Evidence pile:** `affinity-diagrams.md`.
- **High ambiguity or no project object:** use the General section of `full-prompt-library.md`, then ask for the missing community or need if needed.

## Overrides

- If the user names a method, use it.
- If the user says “weird,” “surprising,” or “less obvious,” use `lateral-provocations.md` or `pataphysics.md`, then run a strict feasibility and safeguarding translation.
- If the prompt combines a product request with a mood override, explicitly stack the product framing method and one provocation method only when the user asks for that depth; otherwise pick the closest method and state the trade-off.
- If the same request returns for another round, switch methods so the idea distribution changes.

## Method discipline

Do not cite a method without performing its procedure. Do not load all 22 methods. The selected method should change the shape of the output; the ESC grounding pass should change it again by adding a real community, activity, partner dependency, test, and failure mode.
